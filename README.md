# 🚨 ESCAPE 7 — 담장을 넘어, 도로 위로

교도소 안에서 시작해 고속도로에서 끝나는 **2부작 모바일 웹 게임**.
1부에서 어떻게 빠져나왔는지가 2부의 도주 조건을 그대로 결정한다. 설치 없이 브라우저에서 바로 돌아간다.

**플레이: https://khyun024.github.io/police-chase-escape/**

| 파일 | 역할 |
|---|---|
| `index.html` | 타이틀 허브 — 프롤로그, 전체 게임 설명, 인계 규칙, 기기 기능 진단 |

## 두 게임을 어떻게 붙였나

원래 별개였던 두 게임이 한 작품처럼 보이도록 인터페이스 층을 따로 두었다.

- **공용 디자인 토큰** — `shared.css`가 배경·선·글자색·서체(Pretendard + 모노)와 버튼 모양을 세 화면에 동일하게 적용한다.
  강조색만 챕터별로 갈린다: 1부 주황(`body.ch1`), 2부 적색(`body.ch2`). 2부 캔버스 HUD도 1부와 같은 모노 서체·색으로 맞췄다.
- **암전 전환** — 페이지가 바뀔 때 `#x-fade`가 화면을 덮었다 걷힌다. 새로고침처럼 깜빡이지 않고 장면이 넘어가는 것처럼 보인다.
- **챕터 표시** — 상단 중앙에 `CH.1 감옥 ● ○` / `CH.2 도로 ○ ●` 칩이 떠 있고, 플레이 중에는 자동으로 숨는다.
- **연결 컷신** — 1부 엔딩에서 2부로 넘어가면 메뉴를 건너뛰고 바로 연결 장면이 재생된다(담장 → 숲 → 갓길의 차 → 백미러의 파란 불빛).
  인계 내역을 보여준 뒤 `액셀을 밟는다`를 누르면 곧장 주행이 시작된다. 우측 상단 `건너뛰기`로 즉시 넘길 수 있다.
- **연결 신호** — `sessionStorage`의 점프 플래그와 `?from=prison` 쿼리를 함께 쓴다. 둘 중 하나만 살아 있어도 연결이 끊기지 않는다.

## 이야기

죄수 #7. 형기 11년, 재심 세 번 기각. 가진 건 18개월간 눈으로 외운 순찰 시간표와 세탁실 배관 뒤에 숨긴 휴대폰 한 대뿐이다.
서쪽 감시탑 교대 시간에 발전기가 3분간 멈춘다 — 18개월을 기다린 3분.

**1부**는 A동 감방에서 담장까지. 간수의 손전등 빛에 몸이 닿는 순간 끝이다.
**2부**는 담장 너머 국도. 갓길에 시동이 걸린 채 서 있는 차에 올라타는 순간 사이렌이 켜진다. 이제 발이 아니라 바퀴다.

## 1부 — 7번의 탈옥 (잠입 액션)

A동 감방 → 중앙 복도 → 세탁실 → 옥상 → 담장, 다섯 구역.
붙잡혀도 중간 지점에서 재시작하지만 **붙잡힌 횟수가 기록에 남고 2부로 인계된다.**

| 입력 | 동작 |
|---|---|
| 화면 하단 버튼 / PC `← →` | 이동 |
| `점프` 버튼 / `Space` | 점프 — **길게 누를수록 높이** |
| `웅크리기` / `↓` | 천장이 낮은 통로 통과 |
| `↑` | 사다리 오르기 · 문 열기 |

- 서치라이트에 닿으면 즉시 발각. 간수는 등 뒤를 보지 못한다 — 순찰 주기를 세고 움직여라.
- 난이도 **쉬움**(간수 느림·무적 1.5초) / **보통**(원래 난이도) 선택 가능. 쉬움은 인계 보너스가 70%로 줄어든다.

## 2부 — 경찰 추격 탈출 (도로 주행)

5차선 국도. **순찰차는 항상 뒤에서만 붙고 절대 추월하지 않는다.**
경찰이 가까울수록 좌측 **체포 게이지**가 차오르고, 가득 차면 검거로 게임 오버.

| 입력 | 동작 |
|---|---|
| 폰 좌우 기울이기 | 조향 (시작 순간의 각도가 중립으로 자동 보정) |
| 화면 좌우 드래그 | 조향 (기울기와 병행, 미지원 기기의 기본 조작) |
| 폰 흔들기 | 연막 살포 |
| 우하단 `부스터` (꾹) / PC `Space`·`↑`·`W` | 가속 — 순찰차가 뒤로 밀린다 |
| 좌하단 `연막` / PC `S`·`X`·`↓`·`Shift` | 3초간 경찰 시야 차단 |
| PC `← →`(`A`·`D`) / `P`·`Esc` / `Enter` | 조향 / 일시정지 / 시작·재시작 |

> PC 키 판정은 `e.key`가 아니라 `e.code` 기준이라 **한글 IME가 켜진 상태에서도** 그대로 먹는다.

- **스핀아웃**: 뒤에 붙은 순찰차를 일반 차량 쪽으로 유도해 박게 하면 이탈 +220점. 고득점의 핵심.
- **추돌**: 차량에 부딪혀 속도가 떨어지면 순찰차가 그 틈에 바짝 붙어 뒤를 받는다.
- **스파이크 스트립**: 수배 3등급부터 등장. 밟으면 4초간 속도·조향력 저하.
- `N` 아이템으로 부스터 충전, `S` 아이템으로 연막 보충(최대 4개). 수배 등급은 620m마다 상승.

## 인계 시스템 — 1부 성적이 2부를 바꾼다

담장을 넘는 순간 1부 기록이 `localStorage`(`escape7.handoff`)를 통해 2부로 넘어간다.

| 1부 결과 | 추격 유예 | 보급 | 보너스 |
|---|---|---|---|
| **S** 붙잡힘 0회 | 9초 | 연막 3 · 부스터 100% | +2,000 |
| **A** 1–3회 | 6초 | 연막 2 · 부스터 100% | +1,200 |
| **B** 4–8회 | 3초 | 연막 2 · 부스터 75% | +600 |
| **C** 9회 이상 | 0초 | 연막 1 · 부스터 55% | 체포 게이지 15%로 시작 |

여기에 **탈출 시간 보너스**가 더해진다 — 4분보다 빠른 30초마다 +150점.
최종 점수는 **탈옥 보너스 + 도주 거리 점수**의 합이며, 게임 오버 화면에 1·2부 기록이 함께 표시된다.

허브의 "2부만 플레이"(`chase.html?solo=1`)는 인계를 무시하고 기본 조건(연막 2·부스터 100%·3.2초 후 추격)으로 시작한다.

## 사용한 모바일 기능

허브 화면이 **현재 기기에서 실제로 지원되는 항목만 ✓ 로 표시**하고, 미지원 기능은 자동으로 터치 조작으로 대체된다.

- **DeviceOrientation** — 2부 기울기 조향. iOS 13+는 시작 시 권한 요청, 거부하면 드래그 조향으로 전환. 세로/가로에 따라 `gamma`/`beta` 자동 선택
- **DeviceMotion** — 흔들어서 연막 (가속도 급변 감지)
- **Vibration API** — 충돌·아차 통과·검거 임박·아이템 획득마다 다른 햅틱 패턴
- **Web Audio API** — 오디오 파일 없이 실시간 합성. 속도에 따라 피치가 변하는 엔진음, 거리에 따라 볼륨·요동이 변하는 사이렌
- **Fullscreen + Screen Orientation Lock** — 시작 시 전체화면·세로 고정
- **Screen Wake Lock** — 플레이 중 화면 꺼짐 방지 (일시정지·백그라운드에서 해제)
- **Page Visibility** — 앱을 벗어나면 자동 일시정지, 복귀 시 기울기 중립 재보정
- **Pointer Events / 멀티터치** — 드래그 조향, 버튼 홀드
- **localStorage** — 최고 기록, 설정, 1부→2부 인계 데이터
- **PWA (manifest + service worker)** — 홈 화면에 설치하면 주소창 없는 전체화면 앱, 오프라인에서도 동작
- **safe-area-inset** — 노치·홈 인디케이터를 피한 UI 배치, 회전·해상도 변경 시 레이아웃 재계산

## 실행 방법

**PC**: `index.html`을 브라우저로 열면 키보드로 플레이할 수 있다. (`file://`에서는 센서·Wake Lock·PWA가 동작하지 않는다.)

**폰**: 위 GitHub Pages 주소를 열면 된다. 기울기 조향·Wake Lock·서비스워커는 보안 컨텍스트(HTTPS 또는 localhost)에서만 동작하므로 `file://`로 직접 열면 빠진다.
브라우저 메뉴 → "홈 화면에 추가"로 설치하면 전체화면 앱이 된다.

로컬 서버로 테스트하려면 (Node 또는 Python 필요):

```bash
npx --yes serve -l 8123 .
```

## 밸런스 메모

2부를 봇으로 자동 플레이해 측정한 값이다(인계 없음 기준).

- 차선을 회피하는 봇: 1분에 2,500m(수배 5등급, 체포 게이지 3%) → 2분에 6,500m·10등급·게이지 70% → **약 2분 30초 / 7,200m / 9,000점에서 검거**
- 조향을 아예 하지 않으면 20초 안에 검거된다

난이도를 조절하려면 `chase.html`의 다음 값들을 만지면 된다.

- 차선 수 `const LANES = 5` / 도로 폭 `road.w = Math.min(W*0.92, H*0.86)`
- 경찰 추격 거리 `(210 - heat*11)` — 키우면 더 멀리 떨어져 따라온다
- 동시 순찰차 수 `Math.min(4, 1 + (heat/3|0))`
- 체포 게이지 상승 `capture + p*p*11*dt` / 회복 `relief = (chasing < 0.12 ? 9 : 1.5)`
- 인계 규칙은 `prison.html`의 `Handoff.build()` 한 곳에 모여 있다
