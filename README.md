교도소 안에서 시작해 고속도로에서 끝나는 **2부작 모바일 웹 게임**.
1부에서 어떻게 빠져나왔는지가 2부의 도주 조건을 그대로 결정한다. 설치 없이 브라우저에서 바로 돌아간다.

## 두 게임을 어떻게 붙였나

원래 별개였던 두 게임이 한 작품처럼 보이도록 인터페이스 층을 따로 두었다.

- **공용 디자인 토큰** — `shared.css`가 배경·선·글자색·서체(Pretendard + 모노)와 버튼 모양을 세 화면에 동일하게 적용한다.
  강조색만 챕터별로 갈린다: 1부 주황(`body.ch1`), 2부 적색(`body.ch2`). 2부 캔버스 HUD도 1부와 같은 모노 서체·색으로 맞췄다.
- **암전 전환** — 페이지가 바뀔 때 `#x-fade`가 화면을 덮었다 걷힌다. 새로고침처럼 깜빡이지 않고 장면이 넘어가는 것처럼 보인다.
- **챕터 표시** — 상단 중앙에 `CH.1 감옥 ● ○` / `CH.2 도로 ○ ●` 칩이 떠 있고, 플레이 중에는 자동으로 숨는다.
- **연결 컷신** — 1부 엔딩에서 2부로 넘어가면 메뉴를 건너뛰고 바로 연결 장면이 재생된다(담장 → 숲 → 갓길의 차 → 백미러의 파란 불빛).
  인계 내역을 보여준 뒤 `액셀을 밟는다`를 누르면 곧장 주행이 시작된다. 우측 상단 `건너뛰기`로 즉시 넘길 수 있다.
- **연결 신호** — `sessionStorage`의 점프 플래그와 `?from=prison` 쿼리를 함께 쓴다. 둘 중 하나만 살아 있어도 연결이 끊기지 않는다.

서쪽 감시탑 교대 시간에 발전기가 3분간 멈춘다 — 18개월을 기다린 3분.

**1부**는 A동 감방에서 담장까지. 간수의 손전등 빛에 몸이 닿는 순간 끝이다.
**2부**는 담장 너머 국도. 갓길에 시동이 걸린 채 서 있는 차에 올라타는 순간 사이렌이 켜진다. 이제 발이 아니라 바퀴다.

## 1부 — 감옥 탈출 (센서 8관문)

맨몸으로 여덟 관문을 통과해 담장 밖으로. 관문마다 다른 센서를 쓰고, **지원하지 않는 기능은 자동으로 터치 조작으로 대체**된다.
실패하면 **경보**가 쌓이고, 그 수치가 그대로 2부로 인계된다. 경보 100%면 체포.

| # | 관문 | 쓰는 기능 | 방법 |
|---|---|---|---|
| 1 | 감방 자물쇠 | 가속도 | 창살을 잡고 흔들어 녹슨 자물쇠를 부순다 |
| 2 | 순찰 복도 | 기울기 | 서치라이트를 피해 열쇠까지 굴러갔다 돌아온다 |
| 3 | **철계단 강하** | 마이크 + 가속도 | **천천히, 소리 없이** 스무 칸을 내려간다 |
| 4 | 환기구 창살 | 멀티터치 | 세 손가락으로 리벳 세 개를 동시에 푼다 |
| 5 | 지하 배수로 | 나침반 | 몸을 돌려 지시된 방위를 향한 뒤 걷는다 |
| 6 | 무기고 다이얼 | 진동 | 손끝에 오는 진동으로 세 자리 번호를 찾는다 |
| 7 | 감시탑 아래 | 카메라 | 빛이 올 때 렌즈를 손으로 덮어 어둠 속에 숨는다 |
| 8 | **담장까지 질주** | 가속도 + 탭 | **크게 흔들어 달리고**, 화면 **좌우를 탭**해 피한다 |

### 3관문 — 철계단 강하

간수는 한 층 아래 층계참에 서서 **주기적으로 위를 올려다본다.**

- 폰을 **아래로 아주 살짝** 기울이면 한 칸씩 내려간다. 화면 왼쪽 막대의 **안전선(주황)** 을 넘기면 발소리가 울린다.
- 마이크를 허용하면 **실제 숨소리·소음**도 판정에 들어간다. (허용하지 않으면 속도만으로 판정)
- **간수가 올려다볼 때(👀) 움직이거나 소리를 내면** 의심이 급격히 오른다. 멈춰 있으면 내려간다.
- 의심 100% → 계단 위로 손전등이 비친다(경보 +12, 세 칸 후퇴).

### 8관문 — 담장까지 질주

- **달리기는 흔들기(가속도)** 로만 한다. 세게 흔들수록 빠르다.
- 장애물은 **화면 좌우 탭**으로 세 갈래 길을 오가며 피한다. 흔드는 동작이 기울기 값을 망가뜨리기 때문에, 회피를 탭으로 분리했다.
- 장애물은 항상 세 갈래 중 하나만 막으므로 **탭 한 번이면 반드시 피할 수 있다.**
- 40초 안에 100m. 시간 초과 시 경보 +14와 함께 뒤로 밀린다.

## 2부 — 경찰 추격 탈출 (도로 주행)

5차선 국도. **순찰차는 항상 뒤에서만 붙고 절대 추월하지 않는다.**
경찰이 가까울수록 좌측 **체포 게이지**가 차오르고, 가득 차면 검거로 게임 오버.

| 입력 | 동작 |
|---|---|
| 폰 좌우 기울이기 | 조향 — **잡은 자세를 알아서 중립으로 잡는다**(아래 참고) |
| 화면 두 번 두드리기 | 기울기 중립을 지금 자세로 즉시 재보정 |
| 화면 좌우 드래그 | 조향 (기울기와 병행, 미지원 기기의 기본 조작) |
| 폰 흔들기 | 연막 살포 |
| 우하단 `부스터` (꾹) / PC `Space`·`↑`·`W` | 가속 — 순찰차가 뒤로 밀린다 |
| 좌하단 `연막` / PC `S`·`X`·`↓`·`Shift` | 3초간 경찰 시야 차단 |
| PC `← →`(`A`·`D`) / `P`·`Esc` / `Enter` | 조향 / 일시정지 / 시작·재시작 |

> PC 키 판정은 `e.key`가 아니라 `e.code` 기준이라 **한글 IME가 켜진 상태에서도** 그대로 먹는다.

### 기울기 조향 — 맞출 필요가 없다

세로(포트레이트) 기준이며 `gamma`(좌우로 눕히는 각도)를 쓴다. 절대 각도가 아니라 **지금 잡고 있는 자세 대비 상대 각도**라서, 눕혀 들든 세워 들든 상관없다. 세 겹으로 알아서 맞춰진다.

1. **자동 중립 추종** — 중립값이 현재 각도를 천천히 따라간다. 거의 안 기울인 상태에서는 빠르게(0.7/s), 확실히 꺾고 있을 때는 거의 고정(0.02/s)이라 조향은 그대로 먹으면서 자세 변화·드리프트만 흡수한다.
2. **가장자리 자동 복구** — 손을 대지 않았는데 차가 도로 가장자리에 0.8초 이상 붙어 있으면 중립이 틀어진 것으로 보고 지금 자세로 다시 잡는다.
3. **두 번 두드리기** — 언제든 화면을 두 번 두드리면 즉시 재보정된다.

여기에 **1.5° 데드존**(작은 떨림 무시)과 **16°에서 최대 조향**, 중앙이 부드럽고 끝이 확실한 응답 곡선이 적용된다. 1부의 기울기 관문(순찰 복도·철계단)도 같은 방식이다.

### 판정 규칙 — 전부 화면에 보인다

애매하게 잡히는 일이 없도록, 게이지가 오르는 조건을 눈에 보이는 것만으로 정했다.

- **체포 사거리**: 차 뒤쪽으로 붉은 점선이 그어진다. 순찰차가 **그 선 안에 있는 동안에만** 게이지가 오르고, 가까울수록·같은 차선일수록 빠르다. 선 밖으로 밀어내면 빠르게 회복된다.
- **예고 → 밀어붙이기**: 순찰차는 평소 사거리 밖에서 따라오다가, 머리 위에 **붉은 화살표(“붙는다”)** 를 띄운 뒤에만 사거리 안으로 파고든다. 대응할 시간이 항상 먼저 주어진다.
- **속도가 곧 거리**: 느리게 달릴수록 순찰차가 그만큼 따라붙는다. 사고로 속도를 잃는 것이 진짜 위험이고, 부스터로 속도를 되찾으면 거리도 벌어진다.
- **스침 / 충돌 분리**: 옆을 얕게 스치면 불꽃과 6% 감속뿐이고, 깊게 박았을 때만 충돌로 처리한다. 충돌 직후에는 **1.3~1.7초 무적**(차가 깜빡인다)이라 연쇄 충돌로 무너지지 않는다.
- **스핀아웃**: 순찰차는 평소 앞차를 피해 차선을 고르지만, **밀어붙이는 중(붉은 화살표 뒤)에는 앞을 보지 않고 플레이어만 쫓는다.** 이때 교통 쪽으로 유도해 차 앞으로 빠져나가면 그대로 박고 이탈한다(+220점). 다만 2.4초 뒤 다음 순찰차가 붙는다.
- **막다른 길 없음**: 전방에는 항상 최소 두 개 차선이 비어 있도록 차량이 배치된다.

### 그 밖에

- **스파이크 스트립**: 수배 5등급(쉬움 6등급)부터 등장. 밟으면 2.5초간 속도 저하.
- `N` 아이템으로 부스터 충전, `S` 아이템으로 연막 보충(최대 4개). 수배 등급은 780m마다 상승.
- 부스터는 연료 소모가 크다(약 3초 분량). 만능 탈출기가 아니라 “여는 카드”에 가깝다.

## 인계 시스템 — 1부 성적이 2부를 바꾼다

담장을 넘는 순간 1부 기록이 `localStorage`(`escape7.handoff`)를 통해 2부로 넘어간다.

| 1부 최종 경보 | 추격 유예 | 보급 | 보너스 |
|---|---|---|---|
| **S** 20% 미만 | 9초 | 연막 3 · 부스터 100% | +2,000 |
| **A** 20–49% | 6초 | 연막 2 · 부스터 100% | +1,200 |
| **B** 50–79% | 3초 | 연막 2 · 부스터 75% | +600 |
| **C** 80% 이상 | 0초 | 연막 1 · 부스터 55% | 체포 게이지 15%로 시작 |

여기에 **탈출 시간 보너스**가 더해진다 — 8분보다 빠른 1분마다 +200점.
최종 점수는 **탈옥 보너스 + 도주 거리 점수**의 합이며, 게임 오버 화면에 1·2부 기록이 함께 표시된다.

허브의 "2부만 플레이"(`chase.html?solo=1`)는 인계를 무시하고 기본 조건(연막 2·부스터 100%·3.2초 후 추격)으로 시작한다.

## 사용한 모바일 기능

허브 화면이 **현재 기기에서 실제로 지원되는 항목만 ✓ 로 표시**하고, 미지원 기능은 자동으로 터치 조작으로 대체된다.

- **DeviceOrientation** — 2부 기울기 조향. iOS 13+는 시작 시 권한 요청, 거부하면 드래그 조향으로 전환. 세로/가로에 따라 `gamma`/`beta` 자동 선택
- **DeviceMotion** — 흔들어서 연막 (가속도 급변 감지)
- **Vibration API** — 충돌·아차 통과·검거 임박·아이템 획득마다 다른 햅틱 패턴
- **Web Audio API** — 오디오 파일 없이 실시간 합성. 속도에 따라 피치가 변하는 엔진음, 거리에 따라 볼륨·요동이 변하는 사이렌
- **Fullscreen + Screen Orientation Lock** — 시작 시 전체화면·세로 고정
- **Screen Wake Lock** — 플레이 중 화면 꺼짐 방지 (일시정지·백그라운드에서 해제)
- **Page Visibility** — 앱을 벗어나면 자동 일시정지, 복귀 시 기울기 중립 재보정
- **Pointer Events / 멀티터치** — 드래그 조향, 버튼 홀드
- **localStorage** — 최고 기록, 설정, 1부→2부 인계 데이터
- **PWA (manifest + service worker)** — 홈 화면에 설치하면 주소창 없는 전체화면 앱, 오프라인에서도 동작
- **safe-area-inset** — 노치·홈 인디케이터를 피한 UI 배치, 회전·해상도 변경 시 레이아웃 재계산

## 실행 방법

**PC**: `index.html`을 브라우저로 열면 키보드로 플레이할 수 있다. (`file://`에서는 센서·Wake Lock·PWA가 동작하지 않는다.)

**폰**: 위 GitHub Pages 주소를 열면 된다. 기울기 조향·Wake Lock·서비스워커는 보안 컨텍스트(HTTPS 또는 localhost)에서만 동작하므로 `file://`로 직접 열면 빠진다.
브라우저 메뉴 → "홈 화면에 추가"로 설치하면 전체화면 앱이 된다.

로컬 서버로 테스트하려면 (Node 또는 Python 필요):

```bash
npx --yes serve -l 8123 .
```

## 밸런스 메모

2부를 봇으로 자동 플레이해 측정한 값이다(인계 없음, 5분 상한).

| 플레이 | 쉬움 | 보통(기본) |
|---|---|---|
| 회피만, 부스터·연막 미사용 | 71초에 검거 | 54초에 검거 |
| 붙었을 때 부스터·연막으로 대응 | 5분 생존, 게이지 최대 55% | **4분 15초 / 16,800m에서 검거** |
| 5분간 이탈시킨 순찰차 | 22대 | 19대 |

즉 **도구를 쓰지 않으면 1분 안에 잡히고, 잘 대응해도 결국 따라잡힌다.** 게이지가 100%까지 차려면 사거리 안에 붙어 있는 시간이 누적 6~9초 필요하다.
순찰차를 이탈시켜도 **2.4초 안에 다음 차가 무전으로 붙으므로** 추격이 끊기지 않는다.

난이도를 조절하려면 `chase.html`의 다음 값들을 만지면 된다.

- 난이도 표 `const DIFFS = { easy: {...}, normal: {...} }` — `cap`(게이지 상승 배수), `relief`(회복 배수), `inv`(무적 시간), `traffic`, `speed`
- 체포 사거리 `LOCK = Math.min(car.h*1.7, (H - car.y)*0.72)` — **반드시 화면 안에 들어와야 한다**(선이 보여야 규칙이 보인다)
- 게이지 상승 `capture + p * 17 * DIFF.cap * dt` / 회복 `relief = (chasing < 0.05 ? 9 : ...)`
- 밀어붙이기 주기 `c.mode` 전환부 — 예고 0.75초, 밀어붙이기 2.0초 + 등급 보정
- 속도-거리 연동 `slowPull = (1 - spd) * LOCK * 1.25`
- 차선 수 `const LANES = 5` / 도로 폭 `road.w = Math.min(W*0.92, H*0.86)`
- 인계 규칙은 `prison.html`의 `Handoff.build()` 한 곳에 모여 있다
