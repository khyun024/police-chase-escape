# 🚨 경찰 추격 탈출 (Police Chase Escape)

도로에서 순찰차를 떼어내며 최대한 멀리 도주하는 **모바일 웹 게임**. 설치 없이 브라우저에서 바로 돌아가고, 폰의 센서·진동·화면 기능을 실제로 사용한다.

파일 4개로 끝난다.

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (HTML + CSS + Canvas 게임 로직, 외부 의존성 0) |
| `manifest.webmanifest` | PWA 설치 정보 (전체화면·세로 고정) |
| `sw.js` | 서비스워커 — 한 번 열면 오프라인에서도 실행 |
| `icon.svg` | 홈 화면 아이콘 |

## 게임 방식

- **목표**: **5차선** 도로를 달리며 일반 차량을 피하고, 뒤에서 붙는 순찰차를 떼어낸다. 거리에 비례해 점수가 오른다.
- **순찰차는 항상 뒤에서만 등장하고 절대 추월하지 않는다.** 앞을 막지 않으니 시야는 전방 회피에만 쓰면 된다.
- **체포 게이지(좌측 빨간 바)**: 순찰차가 가까울수록 차오르고, 떼어내면 내려간다. **가득 차면 검거 → 게임 오버.**
- **부스터 게이지(우측 파란 바)**: `부스터` 버튼을 누르면 가속하고 순찰차가 뒤로 밀린다. `N` 아이템으로 충전.
- **연막**: `연막` 버튼 또는 **폰을 흔들면** 살포. 3초간 경찰이 시야를 잃고 뒤로 처진다. `S` 아이템으로 획득(최대 4개).
- **아차 상황**: 차량을 스치듯 통과하면 콤보 배수가 올라 점수가 가산된다.
- **순찰차 스핀아웃**: 경찰도 일반 차량과 부딪히면 이탈한다(+220점). 뒤에 붙은 순찰차를 차량 쪽으로 유도해 박게 만드는 게 고득점 핵심.
- **추돌**: 일반 차량에 부딪혀 속도가 떨어지면 순찰차가 그 틈에 바짝 붙어 뒤를 받는다. 실수 한 번이 검거로 이어지는 구간.
- **스파이크 스트립**: 수배 등급 3 이상부터 등장. 밟으면 4초간 속도·조향력 저하.
- 수배 등급은 620m마다 올라가고 순찰차 수·교통량·추격 집요함이 함께 증가한다.

## 조작

| 입력 | 동작 |
|---|---|
| 폰 좌우로 기울이기 | 조향 (게임 시작 순간의 각도가 중립으로 자동 캘리브레이션) |
| 화면 좌우 드래그 | 조향 (기울기와 병행 가능, 기울기 미지원 기기의 기본 조작) |
| 폰 흔들기 | 연막 살포 |
| 우하단 버튼 (꾹 누르기) | 부스터 |
| 좌하단 버튼 | 연막 |
| PC: ← → (A·D) | 조향 |
| PC: Space (↑·W) | 부스터 |
| PC: **S · X · ↓ · 왼쪽 Shift** | 연막 |
| PC: P·Esc / Enter | 일시정지 / 시작·재시작 |

> PC 키 판정은 `e.key`가 아니라 `e.code` 기준이라 **한글 IME가 켜진 상태에서도** S·X 연막이 그대로 먹는다.

## 사용한 모바일 기능

메뉴의 "이 기기에서 쓸 수 있는 모바일 기능" 카드가 **현재 기기에서 실제로 지원되는 항목만 ✓ 로 표시**하고, 미지원 기능은 자동으로 대체 동작으로 빠진다.

- **DeviceOrientation** — 기울기 조향. iOS 13+에서는 시작 시 권한 요청(`requestPermission`)을 띄우고, 거부하면 드래그 조향으로 전환한다. 세로/가로 방향에 따라 `gamma`/`beta`를 자동 선택.
- **DeviceMotion** — 가속도 급변(jerk)을 감지해 "흔들어서 연막".
- **Vibration API** — 충돌·아차 통과·검거 임박·아이템 획득마다 다른 패턴의 햅틱.
- **Web Audio API** — 오디오 파일 없이 실시간 합성. 속도에 따라 피치가 변하는 엔진음, 경찰과의 거리로 볼륨·요동이 변하는 사이렌, 충돌/스크래치/부스터/펑크 효과음.
- **Fullscreen API + Screen Orientation Lock** — 시작 시 전체화면 진입 및 세로 고정.
- **Screen Wake Lock API** — 플레이 중 화면 자동 꺼짐 방지(일시정지·백그라운드에서 해제).
- **Page Visibility API** — 앱을 벗어나면 자동 일시정지 + 오디오 정지, 복귀 시 기울기 중립 재설정.
- **Pointer Events** — 멀티터치/드래그 조향, 버튼 홀드.
- **localStorage** — 최고 점수·최장 거리·설정(기울기/진동/사운드/흔들기) 저장.
- **PWA (manifest + service worker)** — 홈 화면에 설치하면 주소창 없는 전체화면 앱으로 실행되고, 오프라인에서도 동작.
- **safe-area-inset** — 노치·홈 인디케이터 영역을 피한 UI 배치. 화면 회전·해상도 변경 시 레이아웃 재계산.

## 실행 방법

### 1) PC에서 바로 확인
`index.html`을 브라우저로 열면 된다. (키보드 조작으로 플레이 가능. `file://`에서는 센서·웨이크락·PWA가 동작하지 않는다.)

### 2) 폰에서 제대로 플레이 — HTTPS 또는 localhost가 필요
기울기 조향, Wake Lock, 서비스워커는 브라우저 보안 정책상 **보안 컨텍스트(HTTPS 또는 localhost)** 에서만 동작한다. 셋 중 아무거나 고르면 된다.

- **정적 호스팅에 업로드 (가장 쉽고 확실)**: 이 폴더 4개 파일을 그대로 Netlify Drop / Cloudflare Pages / GitHub Pages 같은 곳에 올리고 폰에서 그 HTTPS 주소를 연다. 이후 브라우저 메뉴의 "홈 화면에 추가"로 설치하면 전체화면 앱이 된다.
- **같은 Wi-Fi에서 로컬 서버 + 터널**: PC에서 아래처럼 서버를 띄우고, `cloudflared tunnel --url http://localhost:8123` 등으로 HTTPS 주소를 만들어 폰에서 접속한다.

  ```bash
  npx --yes serve -l 8123 .
  ```

  Python이 설치돼 있다면 이것도 된다.

  ```bash
  python -m http.server 8123
  ```

  > 이 PC에는 Node도 Python 실행 파일도 없었다(`python`은 Microsoft Store 스텁). 로컬 서버로 테스트하려면 [Node.js](https://nodejs.org) 또는 [Python](https://www.python.org/downloads/) 설치가 먼저 필요하다.

- **HTTP LAN 접속(`http://192.168.x.x:8123`)** 도 게임 자체는 돌아가지만, 기울기 조향·Wake Lock·오프라인 설치는 빠지고 드래그 조향으로 동작한다.

## 밸런스 메모

봇으로 자동 플레이 검증을 돌린 기준값이다(5차선 · 후방 전용 순찰차 기준).

- 차선을 회피하는 봇이 **1분에 2,500m(수배 5등급, 체포 게이지 3%)** — 초반은 여유롭다.
- **2분 지점에서 6,500m / 10등급 / 게이지 70%** 로 압박이 붙고, **약 2분 30초 / 7,200m / 9,000점** 에서 검거된다.
- 조향을 아예 하지 않으면 20초 안에 잡힌다.
- 사람이 플레이하면 순찰차를 일반 차량에 박아 이탈시키는 만큼 기록이 크게 늘어난다.

난이도를 조절하려면 `index.html`의 다음 값들을 만지면 된다.

- 차선 수: `const LANES = 5` / 도로 폭: `road.w = Math.min(W*0.92, H*0.86)`
- 경찰 추격 거리: `(210 - heat*11)` — 값을 키우면 더 멀리 떨어져 따라온다
- 동시 순찰차 수: `Math.min(4, 1 + (heat/3|0))`
- 체포 게이지 상승 속도: `capture + p*p*11*dt` (경찰 AI 루프)
- 게이지 회복 속도: `const relief = (chasing < 0.12 ? 9 : 1.5) ...`
- 기본 속도 상승: `const baseV = 430 + Math.min(560, dist*0.075)`
- 기울기 민감도: `clamp((tiltRaw - tiltZero)/22, -1, 1)` — 숫자를 낮추면 예민해진다
- 흔들기 감지 임계값: `if(jerk > 12 ...)`
